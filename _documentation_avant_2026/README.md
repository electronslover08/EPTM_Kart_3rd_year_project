# 🗂️ Documentation des années précédentes (avant 2026)

Le kart a été le sujet de nombreux projets d'élèves **avant la création de ce dépôt** (2026–2027). Ce dossier rassemble toute la documentation connue de ces projets : rapports, cahiers des charges, schémas, photos, notices, listes de composants…

Le but : qu'un nouvel élève sache ce qui a déjà été fait sur le kart, et pourquoi, avant de le modifier.

## Organisation

Un sous-dossier par projet, nommé comme les dossiers d'année du dépôt :

```
_documentation_avant_2026/
├── nom_AAAA_AAAA/      Projet d'un élève connu
│   └── …               Documents tels qu'ils ont été retrouvés
└── inconnu_AAAA/       Documents dont l'auteur n'est pas connu (année approximative)
```

Si l'année ou l'auteur sont incertains, indique-le dans le tableau ci-dessous plutôt que de deviner.

## ⚠️ Droits d'auteur : à vérifier avant d'ajouter un document

> [!WARNING]
> Ces documents ont été écrits par **d'autres élèves**, avant ce dépôt. Les licences du dépôt (CERN-OHL-P, MIT, CC BY) **ne s'y appliquent pas** : leurs auteurs n'ont jamais accepté de les publier sous ces licences.
>
> Avant de publier un document ici (le dépôt est **public**), il faut l'**accord de son auteur** ou, à défaut, celui du professeur responsable / de l'école. Indique dans le tableau qui a donné son accord. En cas de doute, ne publie pas le document : décris simplement son contenu dans le tableau et indique où il se trouve (par exemple, sur le serveur de l'école).
>
> Pense aussi à retirer les **informations personnelles** (adresses, numéros de téléphone, notes, évaluations) avant publication.
