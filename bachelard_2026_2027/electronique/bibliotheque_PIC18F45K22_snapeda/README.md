## ⚠️ Modèle 3D mal nommé

L'en-tête du fichier `.step` indique `ATMEGA32-16AU.STEP` : c'est un modèle de boîtier TQFP-44 générique (ATmega32), pas un modèle propre au PIC18F45K22. Il convient pour l'encombrement mécanique d'un TQFP-44 0,8 mm, mais le nom interne est trompeur. Fichier laissé tel que fourni.
