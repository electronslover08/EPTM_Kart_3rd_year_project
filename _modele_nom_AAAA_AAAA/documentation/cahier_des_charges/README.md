# 📝 Cahier des charges

Dépose ici ton cahier des charges, en **Word et en PDF** :

```
Cahier_des_charges_kart_Nom.docx
Cahier_des_charges_kart_Nom.pdf
```

Si ton cahier des charges change en cours de projet, **ne remplace pas l'ancienne version** : ajoute la nouvelle à côté (`…_v2.docx`, `…_v2.pdf`) pour garder la trace des choix.
